AI-Powered Resume Screening and Ranking System

🔍 Overview

An AI-based web application that automates resume screening and ranks candidates based on their relevance to a given job description using Natural Language Processing (NLP) techniques.

🎯 Key Features

Upload resumes (PDF/DOCX)
Input job description
Automated text extraction and preprocessing
Resume matching using TF-IDF & Cosine Similarity
Candidate ranking based on similarity score

🧠 Technologies Used

Python, Flask
NLP (Scikit-learn, NLTK/SpaCy)
HTML, CSS, JavaScript

⚙️ Working

Enter job description
Upload resumes
Text preprocessing and feature extraction
Similarity calculation using TF-IDF & Cosine Similarity
Ranked output of candidates

⚠️ Data Privacy

This repository does not include real resumes due to privacy concerns. Only sample/demo data should be used.

🔮 Future Scope

Advanced NLP models (BERT)
Multi-language support
Integration with job portals

📌 Conclusion

This project demonstrates the use of AI and NLP to improve efficiency and accuracy in the recruitment process.
